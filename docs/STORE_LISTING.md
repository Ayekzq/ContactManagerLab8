# Карточка приложения ContactManager

## Название
ContactManager

## Краткое описание (до 80 символов)
Управляйте контактами: добавляйте, редактируйте и находите нужные записи.

## Полное описание
ContactManager — простое приложение для хранения и управления контактами на Android-устройстве.

Основные возможности:
- добавление контактов с именем, номером телефона и электронной почтой;
- редактирование сохранённых записей;
- удаление ненужных контактов;
- поиск по имени, телефону и электронной почте;
- локальное хранение записей в приложении.

Приложение не требует создания учётной записи и не запрашивает разрешение на чтение системной адресной книги. Контактные записи сохраняются в приватном хранилище приложения. Приложение не отправляет их на сервер разработчика. Системная функция Android Auto Backup может резервировать данные приложения в Google Drive в соответствии с настройками устройства и аккаунта Google.

## Возрастной рейтинг
Пройти анкету IARC в Play Console. Категория приложения — инструменты/производительность. Указать фактическое отсутствие насилия, сексуального контента, ненормативной лексики, азартных игр и рекламы, если это подтверждается финальной сборкой. Итоговый рейтинг формируется после отправки анкеты и может различаться по регионам.
