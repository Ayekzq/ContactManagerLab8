# Учебные обращения ContactManager

Это демонстрационные записи для выполнения задания 15. Они не являются реальными сообщениями пользователей.

## Issue 1 — Bug report

**Название:** [BUG] Поиск не находит номер телефона с форматированием  
**Labels:** `bug`, `priority: high`  
**Приоритет:** P1 High  
**Статус:** Resolved (после проверки поиска в версии 1.1.0)

**Описание:** пользователь вводит номер телефона без пробелов и дефисов, но контакт сохранён с префиксом и форматированием. Поиск должен находить один и тот же номер независимо от пробелов, дефисов и скобок.

**Ожидаемый результат:** поиск находит контакт после нормализации номера.  
**Критерий приёмки:** тестовые варианты `+7 (777) 123-45-67` и `7771234567` соответствуют одному контакту.

**Ответ разработчика:** Спасибо за сообщение. Мы проверили нормализацию телефонного номера и внесли исправление в обновление ContactManager 1.1.0. Пожалуйста, проверьте поиск в последней стабильной версии.

## Issue 2 — Feature request

**Название:** [FEATURE] Добавить экспорт контактов в файл  
**Labels:** `enhancement`, `priority: medium`  
**Приоритет:** P2 Medium  
**Статус:** Backlog

**Описание:** пользователь хочет создавать резервную копию контактов в локальный файл и восстанавливать её после переустановки приложения.

**Предлагаемое решение:** добавить экспорт и импорт в явно выбранный пользователем формат; перед импортом показывать подтверждение и предупреждение о замене/объединении записей.

**Критерий приёмки:** экспорт создаёт файл, импорт проверяет формат и не перезаписывает существующие данные без подтверждения.

**Ответ разработчика:** Спасибо за предложение. Мы добавили экспорт контактов в список будущих улучшений. Сначала оценим требования к защите файла и восстановлению данных.

## Issue 3 — Question

**Название:** [QUESTION] Как сохранить контакты перед переустановкой приложения?  
**Labels:** `question`, `priority: low`  
**Приоритет:** P3 Low  
**Статус:** Answered

**Вопрос:** пользователь хочет переустановить приложение и спрашивает, сохранятся ли контакты.

**Ответ разработчика:** Сейчас контакты сохраняются локально на устройстве. Удаление приложения может удалить локальные данные. Перед переустановкой не удаляйте приложение, пока не подготовлена резервная копия. Функция встроенного экспорта/импорта пока рассматривается как улучшение.
