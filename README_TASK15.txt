ContactManager — задание 15: комплект поддержки

Содержимое:
- .github/ISSUE_TEMPLATE/bug_report.md — шаблон сообщения об ошибке
- .github/ISSUE_TEMPLATE/feature_request.md — шаблон предложения функции
- .github/ISSUE_TEMPLATE/question.md — шаблон вопроса
- .github/ISSUE_TEMPLATE/config.yml — настройки Issue templates
- SUPPORT_POLICY.md — политика поддержки и сопровождения
- SUPPORT_CASES.md — три учебных обращения с приоритетами и ответами
- STORE_REVIEW_RESPONSES.md — два учебных ответа на отзывы

Как использовать:
1. Распаковать содержимое архива в корень ContactManagerLab8, сохранив структуру папок.
2. Проверить app/build.gradle.kts: minSdk ожидается 23; текущее targetSdk указать по реальной строке проекта.
3. В GitHub включить Issues в Settings репозитория, если они отключены.
4. Создать labels: bug, enhancement, question, priority: critical, priority: high,
   priority: medium, priority: low, needs-triage, status: resolved, status: backlog.
5. Создать три учебных Issues по SUPPORT_CASES.md; отметить их как учебные/тестовые.
6. Сохранить два ответа на отзывы в STORE_REVIEW_RESPONSES.md. Фактическая публикация ответов в Google Play не выполнялась.
