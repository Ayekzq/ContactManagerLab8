## [1.0.0] - 2026-11-26

### Added
- Add contacts with a name, phone number, and email address.
- Edit saved contact information.
- Delete contacts.
- Search contacts by name, phone number, and email address.
- Store contact records locally on the device using SharedPreferences in JSON format.
- Use the main contact-management features without an internet connection.
