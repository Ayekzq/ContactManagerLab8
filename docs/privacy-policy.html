Политика конфиденциальности ContactManager

Дата последнего обновления: 26 ноября 2026 года

Эта политика описывает обработку данных в приложении ContactManager (далее — «Приложение»). Разработчик: Ayekzq. Приложение предназначено для локального управления контактными записями на Android-устройстве.

1. Какие данные обрабатываются

Пользователь может самостоятельно вводить в Приложение имя контакта, номер телефона и адрес электронной почты. Эти сведения сохраняются в локальном приватном хранилище Приложения на устройстве с использованием Android SharedPreferences.

2. Как используются данные

Введённые сведения используются только для отображения списка контактов, поиска, редактирования и удаления записей. Приложение не считывает системную адресную книгу и не требует разрешения на доступ к контактам устройства.

3. Передача данных и сторонние сервисы

Текущая версия Приложения не содержит серверной синхронизации, учётных записей, рекламных или аналитических SDK. Разработчик не получает контактные записи и не отправляет их на собственные серверы или третьим лицам.

Резервное копирование Android. В текущем манифесте включено системное резервное копирование (android:allowBackup="true"). Android Auto Backup может включать файлы SharedPreferences в резервную копию приложения в Google Drive пользователя, если резервное копирование включено в настройках Android и аккаунта Google. Резервирование выполняется системной службой Android/Google, а не сервером разработчика. Работа и сроки хранения таких копий определяются настройками устройства и условиями сервиса Google.

4. Разрешения

Текущая версия не объявляет разрешения Android для чтения контактов, местоположения, камеры, микрофона или файлов пользователя. Приложение использует собственное приватное хранилище.

5. Хранение и удаление данных

Контактные записи хранятся на устройстве до тех пор, пока пользователь не удалит их в Приложении или не очистит данные Приложения через системные настройки Android. Удаление Приложения также удаляет его локальные данные; системные резервные копии, если они создавались, управляются отдельно настройками Android/Google.

6. Безопасность

Данные размещаются в приватном внутреннем хранилище приложения, доступном в рамках модели безопасности Android. Приложение не реализует собственное дополнительное шифрование записей и не передаёт их по сети. Рекомендуется использовать блокировку экрана и актуальные обновления Android.

7. Данные детей

Приложение не разработано специально для детей и не собирает сведения о возрасте пользователей.

8. Изменения политики

При изменении функций или способов обработки данных политика будет обновляться. Актуальная версия размещается на этой странице; дата обновления указывается в начале документа.

9. Контакт для вопросов о конфиденциальности

Разработчик: Ayekzq. Вопросы и обращения по этой политике можно направить через раздел Issues репозитория ContactManagerLab8 на GitHub. Не публикуйте в открытых обращениях номера телефонов, адреса электронной почты и другие личные данные.
