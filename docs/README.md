- `docs/DATA_SAFETY_DRAFT.md` — подготовленный черновик ответов Data safety.

## Публикация политики через GitHub Pages
1. Скопировать папки `docs` и `store-assets` в корень проекта `ContactManagerLab8` (не перезаписывая остальные файлы).
2. Сделать commit и push в ветку `master`.
3. В GitHub открыть Settings → Pages.
4. В разделе Build and deployment выбрать Deploy from a branch.
5. В Branch выбрать `master`, папку `/docs`, затем Save.
6. После появления статуса Published проверить публичный URL: `https://ayekzq.github.io/ContactManagerLab8/privacy-policy.html`.

Не считать URL опубликованным до фактической проверки в браузере.

## Четыре скриншота приложения
Сделать реальные скриншоты с эмулятора/устройства, а не использовать макеты:
1. Главный экран со списком нескольких тестовых контактов.
2. Окно добавления контакта.
3. Поиск по имени или номеру телефона с результатом.
4. Редактирование контакта или карточка контакта с кнопками изменения/удаления.

Использовать только вымышленные тестовые данные. Снимки сохранить в PNG/JPG без рамок, не закрывая элементы приложения. В Google Play можно добавить 2–8 скриншотов телефона; требования к форматам и размерам проверить в актуальной справке Play Console.
